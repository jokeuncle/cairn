# Experiment ledger

These are reproducible engineering studies, not a commercial certification or
population success-rate leaderboard. Retain every valid failure. Repeated runs
and changed target documents do not create independent task families. Separate
retrieval checks, real Agent acceptance, serialization bytes and billed cost.

[Alpha0.1.0a13 release validation](2026-10-25-release-validation.md) separates
regression gates, source-label adjudication and frozen real Agent evidence.

## Current public-document studies

| Report | Evidence | Outcome |
|---|---|---|
| [Reference analysis](2026-10-25-reference-impact.md) | 8 real Agents; 2 new target instances; native/graph/matched-helper/raw; all42 targets checked independently | All8 accepted; native cost gate failed |
| [Document links](2026-10-25-document-links.md) | 6 completed real Agents; 2 targets; graph/helper/raw; 80 source-pair counts match | All6 accepted; cost gate failed; one separate infrastructure abort retained |
| [Embedding roles](2026-10-25-role-prefix.md) | 6 real Agents on known HTTPX/Starlette tasks; prefix/stock/raw | All6 accepted; prefix cost gate failed; configuration remains opt-in |
| [Native source CLI](2026-10-25-source-cli.md) | 4 real Agents on known tasks | All4 accepted; all token components worse; shortcuts withdrawn |
| [Cross-project confirmation](2026-10-25-cross-project-confirmation.md) | 4 real Agents; new HTTPX/Starlette code tasks; CLI/raw | All4 accepted; conditional price benefit only; strict gate failed |
| [CLI screen](2026-10-25-lean-cli.md) | 10 real Agents; 2 known tasks; five arms | All10 accepted; primary lexical/text cost gate failed |

The last four rows are24 sessions over four tasktexts, not24 independent tasks.
The first two add14 sessions over four target instances of one reference-analysis
template, using pinned public documentation. None is a blind customer workload.

I is cumulative input; K is cached input; U=I−K; O includes reasoning and all
other output. A token-price condition is not an assumed provider bill or TCO.
Model startup, summaries, index storage and amortization are disclosed separately.
Control menu differences, skills, errors and autonomous verification choices
remain in the recorded cost; single observations cannot isolate causality.
